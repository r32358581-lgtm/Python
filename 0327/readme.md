# 반복문
우리 생활에서는 반복적인 작업들이 필요하며 반복적이고 단순한 작업은 컴퓨터를 이용하려 자동화하면 된다.
횟수 반복(for)은 정해진 횟수만큼 반복하고 조건 반복(while)은 특정한 조건이 성립되는 동안 반복한다. 횟수 반복은 반복의 횟수를 미리 아는 경우에 사용한다.
```
for 변수 in 리스트:
    문장 1
    문장 2
```

# 리스트
리스트란 항목들을 저장하는 자료 구조이다. 리스트의 인덱스는 0부터 시작한다.

# range함수
range()함수로 반복 횟수를 전달하면 함수가 자동으로 순차적인 정수들을 생성해준다.

# 무한 루프와 break, continue
```
while True:
    if 조건:
        break > 반복중단
    if 조건:
        continue > 다음 반복 시작
```
