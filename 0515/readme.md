# 객체 지향 프로그래밍
객체 지향 프로그래밍에서는 서로 관련 있는 데이터와 함수를 묶어서 객체로 만들고 객체들이 모여서 하나의 프로그램이 된다.
절차 지향 프로그래밍은 프로시저를 기반으로 하고 객체 지향 프로그래밍은 데이터와 함수를 하나객의 덩어리로 묶어서 생각하는 방법이다.
객체는 속성과 동작을 가진다.

# 클래스
객체에 대한 설계도를 클래스라고 하며 클래스는 특정한 종류의 객체들을 찍어내는 형틀 또는 청사진이라고 할 수 있다. 클래스로부터 만들어지는 객체를 그 클래스의 인스턴스라고 한다.

# 정보 은닉
인스턴스 변수를 private로 정의하려면 변수 이름 앞에 __를 붙이면 된다. private가 붙은 인스턴스 변수는 클래스 내부에서만 접근 가능하다.
접근자(getter), 설정자(setter)

# 클래스 변수
모든 객체를 통틀어서 하나만 생성되고 모든 객체가 이것을 공유하는 변수를 클래스 멤버라고 한다.
```
class Television:
   serial number = 0 > 클래스 변수
```

# 특수 메소드
__add__, __sub__ 등과 같은 연산자와 관련된 특수 메소드가 있다.
