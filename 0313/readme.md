# 변수
변수는 컴퓨터의 메모리 공간에 이름을 붙이는 것으로 값을 지정할 수 있다. 소문자와 대문자 다르게 취급하며 영문자와 숫자, 언더바로 이루어진다.
변수이름 = 값
```
# base=10
# height=10
# area=0.5*base*height
# print(f"밑변 {base}와 높이 {height}인 삼각형의 면적: {area:.2f}")
```

# 불변 객체와 가변 객체
불변 객체는 한번 만들어지면 변경할 수 없고 새 값을 저장하는 새로운 객체가 생성되며 가변 객체는 변경이 가능하다.
불변 객체: 정수, 실수, 문자열...
가변 객체: 리스트, 세트...
