# 코드 묶는 방식
1. 함수는 우리가 반복적으로 사용하는 코드를 묶은 것으로 프로그램의 빌딩 블록과 같다.
2. 객체는 서로 관련 있는 변수와 함수를 묶는 방법이다.
3. 모듈은 함수나 객체들을 소스 파일 안에 모은 것이다.

# 함수
동일한 코드를 반복 처리할 때 유용하다. 함수는 여러번 호출될 수 있다. 매개변수를 변경한다고 해서 인수가 변경되지는 않으며 함수의 매개 변수가 기본값을 가질 수 있는데
이것을 디폴트 인수라고 한다. 인수는 딕셔너리 형태로 전달된다. 함수는 소스 코드의 중복을 없애주고 한번 제작된 함수는 다른 프로그램을 만들 때도 사용가능하다.
